# Estudio financiero

Notas de estudio de inversión de Luis Rodrigo Aguilar, una pestaña por tema.

- **Ingreso recurrente**: cuándo un ingreso que se repite justifica pagar más por él (septiembre de 2026).
- **Interés compuesto**: matemática, historia, lo que dijeron los grandes inversionistas, aplicación en México y biblioteca de recursos (octubre de 2026).

Se consulta en https://luisrodrigoag-pixel.github.io/estudio-financiero/

Para usarlo en el iPad como app: abrir la liga en Safari, tocar Compartir y elegir «Agregar a pantalla de inicio».

Documento de estudio. No constituye recomendación de inversión ni asesoría fiscal.
